## 🌟 Overview

A modern, cinematic personal portfolio showcasing the creative and technical work of **Akash V G** — Computer Science student at College of Engineering Cherthala, AI accessibility researcher, filmmaker/videographer, and full-stack developer.

---

## ✨ Key Features

- **🎬 Cinematic Gold Prologue & Theatrical Curtain:**
  - High-FPS stardust canvas particle simulation with responsive mouse interaction.
  - 3D perspective mouse tilt, golden typography, and ambient optical glow.
  - Theatrical split curtain shutter transition unveiling the hero experience.
  - Keyboard accessible (<kbd>Space</kbd> / <kbd>Enter</kbd> to explore, <kbd>ESC</kbd> to skip, scroll reveal).

- **🎨 Multi-Accent Dynamic Theme Engine:**
  - Real-time accent palette switcher: **Royal Gold & Lux**, **Cinematic Amber**, **Emerald**, **Sunset Rose**, **Cyber Teal**, and **Electric Blue**.
  - Seamless Dark/Light theme switching with persisted user preferences.

- **🔊 Web Audio Synthesizer:**
  - Dynamic procedural sound effects powered by the Web Audio API for interactive micro-feedback.
  - Global audio mute/unmute toggle.

- **🕹️ Interactive Mini-Games & Easter Eggs:**
  - **Whirly Bird:** 2D canvas physics flight simulator with custom controls.
  - **Tic-Tac-Toe:** Unbeatable Minimax AI engine vs player with score tracking.

- **🦾 Flagship Projects:**
  - **SignBridge:** AI-powered interview and communication platform for Deaf & Hard-of-Hearing candidates using Indian Sign Language (ISL).
  - **Kerala Bus Seat Allocation:** Dynamic ticket reservation and smart seat selection system.
  - **GDG Netflix Clone:** High-fidelity media streaming user interface.

- **🏆 Leadership & Experience:**
  - **Videographer** — IEEE SB CECTL
  - **Public Relations (PR) Head** — Training & Placement Cell (TPC CEC)

## 🛠️ Tech Stack

- **Frontend:** Vanilla HTML5, Modern CSS3 (Grid, Flexbox, Custom Properties, Glassmorphism), Vanilla JavaScript (ES6+)
- **Graphics & Sound:** HTML5 Canvas API, Web Audio API
- **Deployment & CI/CD:** GitHub Pages via GitHub Actions (`.github/workflows/deploy.yml`)

## 🚀 Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Akashvg2005/portfolio.git
   cd portfolio
   ```

2. **Run locally:**
   ```bash
   # Using npx serve
   npx serve .
   
   # Or using Python's built-in HTTP server
   python -m http.server 8000
   ```
   Open [http://localhost:8000](http://localhost:8000) or the port displayed in your terminal.
